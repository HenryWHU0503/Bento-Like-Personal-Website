# Bento-Like-Personal-Website

A website that using and imitating the bento layout, yet written in HTML, CSS and JavaScript.

## How to Deploy

Easily fork this repository, and deploy it on GitHub Pages or the folder of your website. And you can see it easily succeed on your server.

## Why to Come Up with This Project

I am a student, and I want to have a personal website to show my projects. I found that the bento layout is a good way to show my projects. Yet I don't want to use any framework to build this website because I want to deploy it on my server. So I decided to come up with this project.

# Bento 风格个人主页

这个主页在使用HTML，CSS和JavaScript的情况下顺利模仿了Bento的风格。

## 如何部署

只需要简单地将这个仓库fork到你的账号下，然后部署到GitHub Pages或你网站的文件夹下即可。你可以在你的服务器上轻松地看到它的成功运行。

## 为什么做这么一个项目

苦逼的中国学生找了很多的网站风格，最终相中了Bento，但是又不想使用Bento的服务（因为速度确实太慢），所以就有了这个项目。

## Liquid Glass

顶部浮动导航、主题菜单和 Bento 卡片共享同一套玻璃材质。支持 SVG 背景滤镜的 Chromium 会按可见组件的尺寸生成位移图，沿圆角折射并放大背景。其他浏览器使用半透明材质、模糊和边缘高光。折射思路参考 [archisvaze/liquid-glass](https://github.com/archisvaze/liquid-glass) 和 [Liquid Glass in the Browser](https://kube.io/blog/liquid-glass-css-svg/)。

图标使用 [Font Awesome Free 7.0.0](https://github.com/FortAwesome/Font-Awesome/tree/7.0.0) 的 Solid 和 Brands 字形。网站本地托管了所用字形的子集，许可证见 [asset/fontawesome/LICENSE.txt](asset/fontawesome/LICENSE.txt)。

在仓库目录运行 `python -m http.server 8000`，打开 `http://localhost:8000` 预览。
